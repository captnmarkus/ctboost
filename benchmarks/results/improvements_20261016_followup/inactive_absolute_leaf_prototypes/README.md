# Inactive absolute-leaf prototypes

These four source files were prepared while the final cross-validation run was
pending, then archived when the user requested that research end after that
round and the validated improvements be released. They have **not been run or
tested**. No real-data model, score, timing, or experiment follows from them.

The manifest records their original paths and exact bytes. They are research
snapshots, excluded from the runtime package and the release validation claim.
They depend on sibling benchmark helpers at their original paths and are not
executable from this archive. Future work would need independent review,
synthetic and native validation, and a new frozen protocol.

The [mathematical note](../absolute_leaf_ridge_hypothesis.md) and
[native-format audit](../absolute_leaf_native_format_audit.md) explain the
proposal and its unresolved validation obligations.
